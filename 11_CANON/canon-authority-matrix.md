## Conflict Resolution
1. Identify the subject.
2. Consult its primary authority.
3. If the primary authority conflicts with a higher-level author truth, the higher authority wins.
4. If equal-authority files conflict, mark the issue DISPUTED.
5. Resolve the conflict explicitly before drafting affected material.
6. Update both the source file and the canon register.

## Important Distinction
`11_CANON/` records active canon decisions. It does not replace the detailed source files that explain those decisions.
