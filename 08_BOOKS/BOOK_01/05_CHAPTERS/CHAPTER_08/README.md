## Workflow
1. Read every file in this package.
2. Read finalized Chapters 1–7 and their continuity records/handoffs.
3. Read Book 1 canon and relevant magic/character documents.
4. Treat finalized canon and continuity as authoritative.
5. Draft the complete Chapter 8 manuscript.
6. Do not invent unsupported mechanisms during drafting.
7. Submit the manuscript for Phase 4 Combined Audit before corrections.

## Chapter function
Create genuine physical and narrative progression:

**unauthorized investigation → physical testing → apparent explanation → contradiction → active recurrence → institutional discovery → unresolved consequence.**

Chapter 8 must feel materially different from Chapters 5–7.

## Hard drafting rule
If the prose creates a need for a new magical mechanism, detection method, security system, lore explanation, or unexplained capability, do not invent it. Flag it for calibration instead.
