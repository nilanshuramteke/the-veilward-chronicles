# 4. Aurelia–Aarav Rivalry Status

## Current State
**Publicly visible rivalry.**

The rivalry has progressed as follows:
1. Existing competitive friction.
2. Private recognition of each other's competence.
3. Mutual but unresolved competitive respect.
4. Direct public comparison during the Chapter 3 evaluation.
5. Other students now have observable reason to recognize them as genuine rivals.

## Important Boundary
Public recognition does NOT mean:
- either character has accepted defeat,
- either character has declared the other superior,
- friendship has formed,
- attraction has begun,
- jealousy has entered the dynamic,
- or the rivalry has been resolved.

## Core Dynamic Going Forward
**Mutual competence + unresolved competition + public visibility.**

Neither character currently holds a permanent advantage in canon.
