# BOOK 02 — THE LOST PATH

## Package Purpose
This folder contains the complete planning architecture for Book Two of **The Veilward Chronicles**.

Book Two expands the world beyond Veilward Academy, deepens the mythology of the Veil, tests Aurelia and Aarav's relationship, and transforms the trilogy's central mystery into an active threat.

## Core Promise
The protagonists search for the truth behind the Lost Path and the First Ember while an unseen intelligence studies their choices.

## End State
The protagonists protect the First Ember, but the Seeker learns the Pattern of the Veil. A temporary breach opens, and the Harbinger enters the Hidden World.
