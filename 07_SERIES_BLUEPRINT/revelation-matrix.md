# Revelation Matrix

## Purpose
This matrix separates actual truth from public belief, character knowledge, and reader revelation timing.

**Rule:** Do not reveal a truth earlier than the book column allows.

## Drafting Rules
1. The table governs reader-facing revelation timing.
2. Earlier books may foreshadow later truths without confirming them.
3. Foreshadowing must support multiple plausible interpretations.
4. Author-only files may be consulted for consistency but must not be echoed into early-book prose.
5. If a revelation is unclear, use the latest permitted column rather than the earliest possible one.

## Revelation States
- **Hint** — suggestive but non-confirming.
- **Evidence** — meaningful proof of something, without complete explanation.
- **Partial Reveal** — one layer of truth becomes clear.
- **Major Reveal** — a central mystery changes meaning.
- **Full Story Relevance** — the truth can be openly used by the narrative.
