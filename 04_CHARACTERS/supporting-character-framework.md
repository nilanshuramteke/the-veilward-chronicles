# Supporting Character Framework

> **Document Type:** Character Design Standard
> **Canon Status:** CONFIRMED FRAMEWORK

## Purpose

This document defines how supporting characters should be created.

## Required Narrative Purpose

Every major supporting character should influence at least one of:

- Plot
- Character growth
- Theme
- World perspective
- Emotional stakes

## Categories

Supporting characters may include:

- Friends
- Rivals
- Mentors
- Faculty
- Family
- Allies
- Opponents

A category is not a personality.

## Independent Life Rule

A supporting character should have:

- Goals
- Fears
- Opinions
- Relationships beyond the protagonists

## Romance Rule

No supporting character should exist only to create jealousy.

Romantic conflict must arise naturally.

## Rival Rule

A rival should challenge a protagonist in a meaningful way.

They do not need to be a villain.

## Mentor Rule

Mentors provide perspective, not perfect answers.

## Family Rule

Family pressure should remain emotionally specific.

Avoid making every family member:

- Cruel
- Controlling
- Automatically opposed to love

## Character Creation Template

When creating a new character, define:

1. Identity
2. Species
3. Role
4. Personality
5. Goal
6. Fear
7. Strength
8. Flaw
9. Key relationships
10. Narrative purpose
11. Character arc
12. Canon boundaries

> **A supporting character becomes memorable when they could continue existing even after leaving the room.**
