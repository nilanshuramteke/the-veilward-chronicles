# Character Directory

> **Document Type:** Character Registry  
> **Purpose:** High-level directory of established and developing characters

## Canon Status Key

- **CONFIRMED** — established canon for the current story scope
- **EXPANDABLE** — established, with future details intentionally open
- **PROTECTED** — deeper information governed by author-only canon
- **PLACEHOLDER** — narrative function exists, identity/details intentionally undefined

# Character Creation Rule

Before adding a new named recurring character, define:

1. Narrative function
2. Relationship to the protagonists
3. Knowledge boundary
4. Book-level importance
5. Whether the character needs a dedicated file

Do not create characters merely to fill scenes.

---

# Directory Maintenance

Update this file when:

- a new recurring character becomes canon,
- a placeholder receives an established identity,
- a character's role materially changes,
- a character becomes important enough to require a dedicated profile.

> **Every recurring character should have a reason to exist beyond occupying space in the story.**
